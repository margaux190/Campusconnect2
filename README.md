# Campusconnect2

##Présentation et objectifs
CampusConnect est une application qui est destinée aux étudiants du campus pour centraliser les événements.
Les objectifs sont de : avoir accès aux événements du campus et à leur mises à jour, faciliter les recherches et les inscriptions des étudiants.

##Etat réel du projet
Le projet est en conception

##fonctionnalités envisagées
Pour la fonctionnalité consulter : afficher le détail des événements
Pour la fonctionnalité rechercher : filtrer les événements par date, catégorie ou lieu
Pour la fonctionnalité s'inscrire : pouvoir s'inscrire ou se désinscrire à un événement
Pour la fonctionnalité gérer : pouvoir créer, modifier ou supprimer un événement en tant qu'organisateur

##Consignes de contribution
Il faut : - Pouvoir choisir ou créer un ticket dans Jira avant de commencer
- Créer une branche depuis main nommée d'après le ticket
- Faire des commits clairs, en référençant le ticket
- Ouvrir une Pull Request vers main et demander une relecture à au moins un membre de l'équipe
- Ne jamais pousser directement sur main
- Mettre à jour la documentation Confluence si la contribution modifie le fonctionnement prévu
